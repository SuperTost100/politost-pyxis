# Fonts

- Figtree (variable, 300–900, roman + italic), by Erik Kennedy. SIL Open Font License 1.1. Fontsource 5.3.0.
- JetBrains Mono (variable, 100–800), by JetBrains. SIL Open Font License 1.1. Fontsource 5.3.0.
- Young Serif (400), by the Young Serif Project Authors (noirblancrouge). SIL Open Font License 1.1. Fontsource 5.3.0 (`@fontsource/young-serif`). Titles.
- Source Serif 4 (variable weight 200–900, roman + italic), by Adobe. SIL Open Font License 1.1. Fontsource 5.3.1 (`@fontsource-variable/source-serif-4`, the `wght` files). Math.

Latin subsets. Bundle them with the app; nothing loads from the network. Take `latin-ext` subsets from Fontsource if you need more languages.
